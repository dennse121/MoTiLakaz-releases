# Mo ti lakaz — releases

Android app files for **Mo ti lakaz**, the shared house store app.

- Download the latest version from **Releases** (right side of this page) and open the `.apk` on the phone.
- Once installed (version 1.2 or newer), the app updates itself: it shows *"Version … is ready"* when a new release is published here.

This repository holds only the installable files, not the source code.
